# Homepage
Mode: Operate. Scope: homepage and shared frontend typography, surfaces, navigation.

## Direction contract
THESIS: A meaningful-date calendar, not an auction landing-page template.
OWN-WORLD: Warm white, peach selected surfaces, charcoal text, clean Manrope typography,
quiet borders, restrained motion, and a single functional calendar/detail composition.
STORY: Choose a date, inspect its available public record, then continue to the existing
claim or detail route. Explain that a higher valid claim can replace the current holder.
FIRST VIEWPORT: Compact headline above a wide month grid and adjacent selected-date
summary. Direct date input and month/year controls are visible. Mobile stacks the summary
under the grid; decorative marketing must not bury either.
FORM: User-pinned calendar-first direction, approved in chat. concept-seed attempted,
but engine 0.1.5 unavailable; no generated assignment or seed key is claimed.
SIGNATURE: Selecting a calendar day updates an inline record panel without navigation.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review,
the verdict, DESIGN.md, and every shipping raster carrying its provenance

Implementation path: code-first fallback, not a stored global workflow preference.
No new shipping raster assets are required for this functional calendar surface.
